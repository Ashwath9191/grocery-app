# Grocery App

A modern grocery shopping Android app built using Kotlin and XML.

---

## Features

- Login page
- Grocery product pages
- Add to cart
- Quantity increase/decrease
- Search products
- Checkout screen
- Order success screen
- Dark mode support
- Smooth page animations

---

## Tech Stack

- Kotlin
- XML
- RecyclerView
- Android Studio
- Material Design

---

## How to Run

1. Open project in Android Studio
2. Sync Gradle
3. Run app on emulator or Android device
